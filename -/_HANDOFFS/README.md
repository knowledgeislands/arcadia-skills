# Outgoing handoffs

Place an implementation-ready brief here when work originating in this repository belongs to another repository or external recipient.

The receiving repository owns the priority, roadmap item, plan, implementation, and delivery. A handoff records the originating context and agreed boundaries; it does not transfer control of the work.

Keep handoffs grouped by receiving repository, as in [ki](ki/).

There are currently no active outbound handoffs. The former knowledge-acquisition briefs have been adopted by `tools-ki` and KI Specifications as the local ChatGPT importer and KIS-0002 respectively.

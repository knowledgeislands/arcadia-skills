# Incoming handoffs

Place a handoff received from another repository here while this repository decides whether and how to adopt it.

An adopted handoff becomes an item in this repository's own roadmap. When its execution detail merits preservation, a thematic repository records that detail in an open plan with a non-empty `transferred-from` origin; the plan does not imply readiness.

Remove material that is declined, superseded, or has reached its durable destination. This working inbox is not an archive.

# Phase 5 synthesis

Phase 5 reviewed all eight environment and runtime-adapter skills in dependency order. All propose `revise`; none is graded or remediated.

## Reconciled architecture

- Portable binding and tokenomics policies retain useful runtime-neutral ownership when they report only declared inventory and configuration.
- Claude, Codex, and chezmoi adapters remain the right owners for native projection and bounded filesystem observation.
- Native platform behavior, third-party tool output, user overrides, source projection, registration, activation, and effective session state require independent evidence.
- Safe native writers and no-secret filesystem inventories retain value even where hosted audit coverage or runtime outcome evidence is incomplete.

## Cross-cutting findings

1. Name-set parity cannot prove transport, full-definition equivalence, authentication, reachability, enabled state, or usable tools.
2. Canonical source, deterministic render, applied target, client registration, installed cache, activation, and loaded capability are separate states.
3. A runtime adapter may pass only directly observed filesystem or native-command evidence; effective model and context require an authorized session source.
4. Missing or unreadable runtime evidence must be unavailable, not informational clean state or unconditional policy pass.
5. XDG, override, hierarchy, import, memory, and configuration resolution must be shared or proven equivalent across root, renderer, and rubric.
6. Runtime-specific authority cannot be inferred across products, nor can native platform behavior be inferred from a third-party helper's output.
7. Secret-safe inspection requires value avoidance, explicit preview boundaries, and authorization before rendering, applying, or reading session-derived state.

## Phase boundary decision

Phase 6 may now review the aggregate Harness after all declared dependencies, then `ki-bootstrap` last. Aggregate review must not inherit assurance from unavailable hosted adapters or clean component shape. No Phase 5 finding is applied before approval.

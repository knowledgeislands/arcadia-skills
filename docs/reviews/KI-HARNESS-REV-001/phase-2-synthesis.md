# Phase 2 synthesis

All 11 change-management skills are reviewed and ungraded. Every one currently proposes `revise`; none proposes retirement, consolidation, splitting, or replacement. The existing review order remains valid.

## Reconciled architecture

- The base owns explicit adapter selection and an abstract lifecycle interface.
- The roadmap adapter owns the concrete local record and five-status model, reused within the KB Streams container.
- Remote adapters presently own configuration and safety guidance only; their descriptions overstate process availability.
- Process skills retain distinct selection, shaping, delivery, batch, and closure authority, but must consume one selected-adapter resolver.

Existing `KI-HARNESS-FND-014` remains the owner for selected-adapter resolution and authorised remote execution. It should be enriched only after approval; this review does not amend it.

## Cross-cutting findings

1. Roadmap audit can hide missing-root and dependency failures because inspector codes do not match published criteria.
2. GitHub and Linear record locators change on namespace/team moves; neither current adapter defines migration identity.
3. Every shared process hard-codes local roadmap/Streams paths and therefore cannot execute remote selections.
4. Housekeeping, `ki-next`, and `ki-accept` disagree about spawn versus successful-completion state.
5. Recap and next contain stale Codex compaction claims; recap also parses an explicitly unstable transcript format and can map Git failure to clean evidence.
6. Batch authority can widen from one declared repository into body prose naming several, without payload integrity.
7. Implementation, roadmap, and acceptance do not share one exact review-packet schema.
8. Acceptance's KB prune root and trade-retention checks are incomplete.
9. Process skills have little or no direct behavioral or assisted-versus-baseline evidence.

## Phase boundary decision

Phase 3 may proceed in the existing order. No remediation, grade, or new work item is authorised. Later governance reviews must treat lifecycle records and clean audits as provisional where these defects affect their evidence.
